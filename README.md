# Fanta Eleven

Web app per stimare la probabilità di titolarità dei giocatori di Fantacalcio.

Versione stabile: 4.0.0

- storico partite e minuti da ESPN JSON
- fonti editoriali per la prossima gara
- intervallo di stima e livello di confidenza
- gestione di più fantasquadre e rose
- centro giornata con countdown, alert e variazioni
- confronto “Chi schiero?” e panchina consigliata
- calibrazione anti-appiattimento delle probabilità
